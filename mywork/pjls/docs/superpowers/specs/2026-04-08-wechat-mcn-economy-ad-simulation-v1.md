# 微信小游戏经济演算与广告回收样例 V1

## 1. 文档用途

本文件用于在已有章节数值基础上，进一步回答两个问题：

1. 每个章节里程碑下，玩家自然收益大概能达到什么水平。
2. 各类广告在这些里程碑上的价值是否合理，会不会破坏正常经营节奏。

本文件不直接替代基础数值表，而是作为商业化和数值平衡之间的桥梁文档，帮助团队判断：

1. 哪些广告是健康加速。
2. 哪些广告会在短会话里显得过强。
3. 当前离线收益系数是否适合微信小游戏首版节奏。

## 3. 核心公式口径

本文件统一采用以下近似公式：

1. `effective_traffic_per_sec = (主角有效流量 + 上阵主播流量之和) x 房间流量系数 x 公司流量系数`
2. `natural_sales_gold_per_min = 有效流量/秒 x 60 x 商品转化率 x 商品利润系数 x 主角带货系数 x 房间带货系数 x 公司带货系数 x 团队带货系数`
3. `offline_gold_30m = natural_sales_gold_per_min x 30 x 0.55`
4. `offline_gold_2h = natural_sales_gold_per_min x 120 x 0.55`
5. `ad_live_accelerate_bonus_gold = natural_sales_gold_per_min x 3`
6. `ad_sales_burst_bonus_gold = natural_sales_gold_per_min x 2.4`

说明：

1. `加速广告` 的本质是额外赠送 `3 分钟自然收益`。
2. `爆单广告` 的本质是额外赠送 `2.4 分钟自然收益`。
3. `离线双倍广告` 的本质是把离线部分再补一份，所以其强度完全取决于离线收益系数和离线时长。

## 4. 固定广告等价分钟

从公式角度看，首版几个核心广告的“自然分钟等价”如下：

| 广告类型 | 等价自然收益 |
| --- | --- |
| 开播加速 | `+3 分钟` |
| 爆单翻倍 | `+2.4 分钟` |
| 30 分钟离线双倍额外奖励 | `+16.5 分钟` |
| 2 小时离线双倍额外奖励 | `+66 分钟` |

这里最需要注意的是：当前样例里 `offline_income_coeff = 0.55`，导致离线双倍的强度明显高于主动观看类广告。

## 6. 关键结论

### 6.1 加速和爆单本身是健康的

因为这两个广告本质上分别只多给 `3 分钟` 和 `2.4 分钟` 的自然收益，所以单次强度是稳定的。它们会随着阶段变强，但不会突然失控。

这类广告更适合在：

1. 章节中段卡点
2. 新商品刚解锁后
3. 公司升级前后

### 6.2 离线双倍目前偏强

当前样例的最大问题不在加速和爆单，而在离线收益系数。按现配置，玩家只离开 `30 分钟`，额外补回来的双倍奖励就相当于 `16.5 分钟自然收益`。

这对一款主打 `1-3 分钟短会话` 的微信小游戏来说偏重了，容易导致：

1. 玩家上线先领一大笔，再把主动经营当成收尾动作。
2. 正常章节推进的重要性被离线奖励稀释。
3. 广告看起来不是“加速成长”，而像“直接代替成长”。

### 6.3 免费招募广告在后期会显得偏弱

从纯金币价值看：

1. 第 3 章免费招募约等于 `1800` 金币，仍然有明显吸引力。
2. 第 4 章以后，加速和爆单广告单次增益都远高于免费招募。
3. 第 5 章时，免费招募如果没有附带额外奖励，容易被玩家认为“内容有用但数值不划算”。

因此首版建议：

1. 第 3 章保留纯免费招募。
2. 第 4 章开始，免费招募可以附带少量金币或流量包。
3. 第 5 章开始，免费招募最好附带 `额外流量包` 或 `主播培养资源`。

## 7. 短会话叠广告风险

如果把“加速”和“爆单”都塞进同一段短会话里，广告占比会明显升高。

以下为 `6 分钟短会话` 的简单压力测试：

| 章节收章 | 6 分钟自然收益 | 同时观看加速和爆单的总增益 | 广告贡献占比 |
| --- | --- | --- | --- |
| 第 1 章 | 1002 | 502 | 33% |
| 第 2 章 | 3108 | 2795 | 47% |
| 第 3 章 | 10986 | 9890 | 47% |
| 第 4 章 | 36234 | 32609 | 47% |
| 第 5 章 | 94944 | 85450 | 47% |

这说明：

1. 第 2 章以后，不应在同一段 5-6 分钟短会话里强推两种强广告。
2. 更稳的做法是把加速和爆单拆到不同节点。
3. 优先让玩家每段短会话只感知到一种核心广告价值。

## 8. 首版建议阈值

如果要保持轻放置和广告变现的平衡，建议控制在以下区间：

1. 单次主动广告最好控制在 `2.5-4 分钟自然收益` 内。
2. 30 分钟离线双倍的额外奖励，建议不要超过 `6-10 分钟自然收益`。
3. 单段 5-6 分钟会话里的广告贡献占比，建议不超过 `35%-40%`。
4. 免费招募广告在第 4 章以后，最好补足附加奖励，避免纯数值吸引力掉得太快。

## 9. 调整建议

基于当前样例，最值得优先处理的是离线收益，而不是主动观看类广告。

### 9.1 推荐优先方案

把 `offline_income_coeff` 从 `0.55` 下调到 `0.22-0.28` 区间，首轮建议先试 `0.25`。

这样做的效果是：

1. 30 分钟离线双倍额外奖励从 `16.5 分钟自然收益` 降到 `7.5 分钟自然收益`。
2. 2 小时离线双倍额外奖励从 `66 分钟自然收益` 降到 `30 分钟自然收益`。
3. 回流仍然有惊喜，但不会直接压过主动经营。

### 9.2 备选方案

如果不想直接改全局系数，也可以用章节式限制：

1. 第 1-2 章离线收益系数保留偏高，帮助早期回流。
2. 第 3 章开始逐步下调离线收益系数。
3. 第 4-5 章对离线双倍广告加上章节内奖励上限。
