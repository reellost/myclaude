# 模块 01：开场剧情与新手引导 PRD

## 1. 模块定位

该模块负责把“被辞退的女主播重新出发”这一题材，在最短时间内转化为玩家可理解、可代入、可操作的首轮体验。

它既是剧情入口，也是首轮教学入口，必须同时完成两件事：

1. 让玩家愿意代入女主。
2. 让玩家在 60 秒内完成第一次成长闭环。

## 2. 设计目标

1. 用轻喜剧方式交代女主被辞退，不制造沉重情绪。
2. 让玩家迅速理解“升级自己 -> 开播 -> 产流 -> 带货 -> 收益 -> 再升级”的逻辑。
3. 尽快让玩家拿到第一次正反馈和第一次广告反馈。

## 3. 玩家体验目标

玩家的第一轮体验应该是：

1. 我有点惨，但还挺可爱。
2. 我只要点几下，就能让她变得更好。
3. 她真的开始播了，而且真的赚到钱了。
4. 这个游戏不难，我想继续帮她往上走。

## 4. 功能范围

MVP 需要包含：

1. 开场短剧情演出
2. 女主首次化妆或穿搭引导
3. 第一次直播间整理引导
4. 第一次开播引导
5. 第一次商品选择引导
6. 第一次收益领取
7. 第一次升级引导
8. 第一次激励广告引导

MVP 不包含：

1. 多分支剧情
2. 长篇对白
3. 可跳转的复杂教学菜单

## 5. 核心剧情结构

推荐用 5 个极短节点完成开场：

1. 女主被前公司辞退，情绪低落但不狼狈。
2. 她回到房间，决定试试自己开播。
3. 玩家帮她简单整理形象和直播角落。
4. 第一场直播开始，观众逐步进入。
5. 第一笔收益到账，女主获得继续努力的信心。

单段剧情建议控制：

1. 单条文案不超过 18 个字。
2. 连续剧情不超过 4 屏。
3. 首次进入可看，二次进入默认跳过。

## 6. 新手引导流程

推荐强制引导顺序：

1. 点击“开始直播人生”
2. 进入化妆或穿搭入口，完成一次免费升级
3. 进入直播间入口，完成一次基础设备摆放
4. 点击“开播”
5. 观看流量开始增长
6. 点击商品位，选择第一件基础商品
7. 领取第一笔收益
8. 再次升级主角或直播间
9. 触发第一次广告引导，展示“双倍收益”价值

## 7. 页面与交互

涉及页面：

1. 开场剧情页
2. 主直播间主页
3. 主角成长弹窗
4. 直播间成长弹窗
5. 商品选择弹窗
6. 收益领奖弹窗
7. 广告引导弹窗

交互要求：

1. 新手阶段只能点主路径按钮。
2. 非核心按钮置灰或隐藏。
3. 每一步操作都要给出明显反馈。

## 8. 数值与配置建议

新手阶段应保证：

1. 首次升级后流量立刻上涨。
2. 开播后 5-10 秒内出现第一波收益反馈。
3. 第一轮带货商品利润足够低门槛，但能明显看到订单增长。
4. 第一次广告奖励至少等于玩家当前 1-2 次常规点击收益。

## 9. 文案与演出建议

文案基调：

1. 不卖惨
2. 有点腼腆
3. 有点可爱
4. 轻松自嘲

演出重点：

1. 女主外形变好看
2. 房间从乱到整洁
3. 观众数字上涨
4. 第一笔收入到账

## 10. MVP 边界

首版只验证“剧情是否帮助玩家更快代入”，不追求做剧情向产品。

因此要控制：

1. 不做剧情树
2. 不做复杂人物关系
3. 不做大量过场动画

## 11. 验收标准

1. 玩家能在 60 秒内完成第一轮闭环。
2. 玩家不会在新手阶段迷失，不会出现“下一步做什么”的困惑。
3. 开场故事能被记住，但不拖节奏。
4. 首次广告触发时，玩家能明显理解其价值。
