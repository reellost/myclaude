# 模块 05：带货收益系统 PRD

## 1. 模块定位

带货收益系统负责把流量资源转化为金币收益，是整个经营闭环中“赚钱”的核心实现。

## 2. 设计目标

1. 让玩家直观理解“有流量就能赚钱”。
2. 提供轻量经营决策，但不增加理解负担。
3. 成为广告翻倍、任务目标、章节推进的关键挂钩点。

## 3. 玩家体验目标

玩家应该感受到：

1. 我不是单纯看数字涨，我是在做带货赚钱。
2. 商品换得更好，收益确实更高。
3. 流量越高，爆单爽感越强。

## 4. 功能范围

MVP 包含：

1. 商品位系统
2. 商品选择系统
3. 自动转化收益
4. 订单和收益反馈
5. 商品位升级

MVP 不包含：

1. 手动砍价或互动玩法
2. 库存管理
3. 物流模拟
4. 商品品质随机系统

## 5. 核心规则

### 5.1 商品位

首版建议：

1. 初始开放 1 个商品位
2. 中后期逐步解锁到 2-3 个商品位

### 5.2 商品分类

首版建议 3 类商品赛道：

1. 入门型：低利润，高转化
2. 成长型：中利润，中转化
3. 爆款型：高利润，低转化

### 5.3 收益逻辑

推荐公式方向：

`金币收益 = 当前流量 x 商品转化率 x 商品利润系数 x 带货加成`

其中带货加成来自：

1. 主角技能
2. 直播间功能设备
3. 公司选品能力
4. 临时 Buff

## 6. 页面与交互

入口建议：

1. 主界面商品位直接点击
2. 或单独商品选择弹窗

页面应展示：

1. 当前商品名称
2. 当前商品转化率
3. 当前商品利润级别
4. 切换商品后的收益预估
5. 商品位升级收益

交互要求：

1. 商品选择不要超过 3 次点击
2. 切换商品后收益预估要明确
3. 爆单时要有明显演出和音效提示

## 7. 内容配置建议

首版建议：

1. 每类商品赛道至少 3-5 个配置档
2. 章节推进时逐步开放更高收益商品
3. 不同章节主推商品可以形成轻量主题变化

## 8. 与其他模块的关系

1. 直接消费模块 04 的流量资源
2. 产出金币供模块 02、03、06、07 使用
3. 与模块 09 的“爆单翻倍”广告点强绑定
4. 与模块 08 的销售额任务强绑定

## 9. MVP 边界

首版只做“自动结算 + 轻选择 + 爆单反馈”，不做复杂商品经营。

## 10. 验收标准

1. 玩家能轻松理解商品不同带来的收益差异。
2. 收益反馈足够频繁，能承接放置节奏。
3. 商品系统不会压过主角和房间成长，而是作为赚钱桥梁存在。
4. 爆单反馈足够爽，能支撑广告翻倍场景。
