# 模块 02：主角成长系统 PRD

## 1. 模块定位

主角成长系统是前期个人逆袭阶段的核心驱动力，负责承接玩家对女主的情绪投入，并把“变美、变强、变自信”转化为清晰的数值成长。

## 2. 设计目标

1. 让玩家愿意持续给女主投入资源。
2. 每次成长都能直接反馈到直播表现或带货效率。
3. 用尽量少的系统数量做出“养成感”。

## 3. 玩家体验目标

玩家应该感受到：

1. 我在帮她变得更专业。
2. 她每次升级都看得见变化。
3. 她越强，我赚钱越快。

## 4. 功能范围

MVP 包含三条可操作成长线和一条包装线：

1. 化妆成长
2. 直播技能成长
3. 穿搭成长
4. 心态成长表现

MVP 不包含：

1. 复杂技能树
2. 随机词条
3. 多货币养成材料
4. 深度换装自由搭配

## 5. 核心规则

### 5.1 化妆成长

作用：

1. 提升基础流量
2. 提升开播吸引力

表现：

1. 妆容阶段变化
2. 头像或立绘变化

### 5.2 直播技能成长

作用：

1. 提升流量产出效率
2. 提升带货转化效率

建议技能方向：

1. 镜头表现
2. 表达能力
3. 互动能力

### 5.3 穿搭成长

作用：

1. 提升角色魅力值
2. 提升流量上限或额外加成

表现：

1. 外观阶段变化
2. 特定章节解锁新风格

### 5.4 心态成长

心态成长不单独做复杂系统，建议作为章节包装表现：

1. 从紧张
2. 到适应
3. 到自信

主要作用是强化情绪成长，不额外增加理解成本。

## 6. 数值关系建议

推荐把主角成长拆成统一资源消耗：

1. 使用金币升级
2. 某些关键阶段由章节目标解锁

推荐公式方向：

1. 主角基础流量 = 初始值 x 化妆系数 x 穿搭系数
2. 主角带货效率 = 初始值 x 技能系数

建议首版所有成长项都只影响两个核心值：

1. 流量产出
2. 带货转化

## 7. 页面与交互

页面入口：

1. 主直播间主页中的“主角成长”按钮

页面结构建议：

1. 顶部展示女主当前形象
2. 中部展示三条成长线
3. 每条成长线显示当前等级、下一级收益、升级花费
4. 底部展示综合提升预览

交互要求：

1. 升级前看到数值变化预览
2. 升级后立即播放外观或数值反馈
3. 关键阶段可触发一句短文案，体现女主成长

## 8. 配置建议

首版建议每条成长线至少有：

1. 10-20 个等级点
2. 3 个阶段外观变化
3. 1 个关键章节解锁点

## 9. 与其他模块的关系

1. 为模块 04 提供基础流量输入
2. 为模块 05 提供带货转化加成
3. 与模块 03 一起构成前期主要投入方向
4. 与模块 01 一起组成新手体验主链路

## 10. MVP 边界

首版只做“看得见的阶段变化”和“明确的数值提升”，不做复杂自定义。

## 11. 验收标准

1. 玩家能清楚理解三条成长线分别提升什么。
2. 每次升级后都能看到至少一个明显反馈。
3. 主角成长的投入回报比足够高，不会被房间成长完全压制。
4. 前 2 章内主角成长是最主要的可玩内容之一。
