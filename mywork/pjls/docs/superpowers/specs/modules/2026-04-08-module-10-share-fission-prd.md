# 模块 10：分享裂变系统 PRD

## 1. 模块定位

分享裂变系统负责适配微信小游戏生态，用轻社交方式推动新增、回流和展示传播。

## 2. 设计目标

1. 让分享看起来像“展示成果”，而不是强制任务。
2. 让助力奖励与成长强绑定。
3. 用尽量低的社交压力实现自然传播。

## 3. 玩家体验目标

玩家应该感受到：

1. 我分享是因为我有东西值得晒。
2. 朋友帮我一下，我确实会更快成长。
3. 这个分享不尴尬，不像硬拉人头。

## 4. 功能范围

MVP 包含：

1. 成长海报分享
2. 助力领奖逻辑
3. 分享缩短等待或获得资源
4. 基础邀请奖励

MVP 不包含：

1. 深度社交排行榜
2. 社群公会系统
3. 复杂邀请任务链

## 5. 核心玩法建议

### 5.1 成长海报

海报建议展示：

1. 女主当前形象阶段
2. 直播间当前阶段
3. 今日收益或累计收益
4. 公司当前阶段称号

### 5.2 助力奖励

建议首版奖励：

1. 宣传流量包
2. 招募等待缩短
3. 一次免费招募机会
4. 小额加速奖励

### 5.3 邀请奖励

建议控制上限，避免玩法过重：

1. 首次邀请奖励偏强
2. 连续邀请奖励递减
3. 不做必须拉满人数才能继续主线的设计

## 6. 页面与交互

涉及入口：

1. 主界面分享按钮
2. 章节完成后弹出的分享展示
3. 海报预览弹窗
4. 助力领奖弹窗

交互要求：

1. 分享内容必须好看、直观、可晒。
2. 奖励说明必须简单明了。
3. 不强制玩家频繁分享才能玩下去。

## 7. 与其他模块的关系

1. 模块 02 和 03 提供“变美”和“房间升级”的分享素材。
2. 模块 06 提供公司阶段展示。
3. 模块 08 可将分享作为日常任务补充项。
4. 模块 09 的部分奖励可与分享共同组成回流刺激。

## 8. MVP 边界

首版只做“可展示、可助力、可领奖”的轻裂变机制，不做复杂社交链路。

## 9. 验收标准

1. 分享内容足够有展示欲。
2. 助力奖励能明显帮助成长，但不会破坏数值平衡。
3. 玩家不分享也能正常推进主线。
4. 分享系统与微信小游戏生态能力能自然适配。
