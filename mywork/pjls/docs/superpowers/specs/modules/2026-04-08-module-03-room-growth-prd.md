# 模块 03：直播间成长系统 PRD

## 1. 模块定位

直播间成长系统负责承接“房间从简陋到精致”的视觉成长，也是前期最容易被玩家感知到的环境反馈系统。

## 2. 设计目标

1. 让玩家一眼看出自己变强了。
2. 让房间变化成为女性向用户的重要满足点。
3. 把装修成长做成简单、线性的轻系统。

## 3. 玩家体验目标

玩家应该感受到：

1. 这个直播间越来越像样了。
2. 我每投一次资源，房间都更漂亮、更专业。
3. 房间升级不只是好看，确实能帮我赚更多。

## 4. 功能范围

MVP 仅做阶段式直播间成长，包含：

1. 基础设备升级
2. 房间布置升级
3. 氛围包装升级
4. 带货功能设备升级

MVP 不包含：

1. 自由摆放编辑器
2. 多房间装修方案切换
3. 深度家具收集系统

## 5. 成长分类

### 5.1 基础设备

内容：

1. 手机
2. 补光灯
3. 麦克风
4. 摄像头

数值作用：

1. 提升直播稳定性
2. 提升基础流量效率

### 5.2 房间布置

内容：

1. 背景墙
2. 桌椅
3. 地毯
4. 小装饰物

数值作用：

1. 提升房间品质值
2. 提升整体流量加成

### 5.3 氛围包装

内容：

1. 灯效
2. 色调主题
3. 装饰贴纸

数值作用：

1. 提升人气加成
2. 增强分享视觉效果

### 5.4 功能设备

内容：

1. 商品展示台
2. 货架
3. 简化物流区

数值作用：

1. 提升带货效率
2. 提升商品收益加成

## 6. 数值关系建议

建议房间成长只影响两种核心加成：

1. 流量加成
2. 带货加成

推荐结构：

1. 基础设备和房间布置偏向流量
2. 功能设备偏向带货
3. 氛围包装兼顾轻量综合加成

## 7. 页面与交互

入口：

1. 主直播间主页点击房间热点
2. 或通过固定“直播间升级”按钮进入

页面结构建议：

1. 中间展示当前直播间全景
2. 下方四类成长分页
3. 每类显示当前等级、升级效果、花费
4. 右侧展示升级后预览

交互要求：

1. 升级前后对比明显
2. 部件替换结果立即可见
3. 不允许玩家在首版中陷入复杂布置选择

## 8. 内容配置建议

首版建议：

1. 直播间至少有 3 个大阶段外观
2. 每个阶段包含 4-6 个可升级点
3. 与章节推进绑定 2-3 次明显换景

## 9. 与其他模块的关系

1. 与模块 02 一起构成前期投入重点
2. 为模块 04 提供流量加成
3. 为模块 05 提供带货环境加成
4. 为模块 10 提供可分享视觉素材

## 10. MVP 边界

首版不做高自由度装修，只做“低选择成本、高反馈”的阶段成长。

## 11. 验收标准

1. 玩家能明显看到房间从差到好的变化。
2. 房间升级收益足够直观，不会像纯装饰。
3. 房间系统不会因为入口太深而被忽略。
4. 房间成长与主角成长在前 2 章形成平衡投入关系。
