# 模块 09：广告与离线收益系统 PRD

## 1. 模块定位

广告与离线收益系统是首版的核心商业化模块，负责把碎片化体验、回流和广告变现自然绑定在一起。

## 2. 设计目标

1. 让广告服务于成长，而不是打断成长。
2. 让离线收益成为回流的第一驱动力。
3. 让广告收益足够明显，值得点。

## 3. 玩家体验目标

玩家应该感受到：

1. 我不上线也有积累。
2. 我上线以后，马上能领一波收益。
3. 看广告是为了更快成长，而不是被迫忍受打扰。

## 4. 功能范围

MVP 包含：

1. 离线收益结算
2. 离线双倍领取广告
3. 升级加速广告
4. 免费招募广告
5. 爆单翻倍广告
6. 基础插屏广告策略

MVP 不包含：

1. 过多广告点位堆叠
2. 强制长链路广告任务
3. 复杂广告商店系统

## 5. 核心规则

### 5.1 离线收益

建议规则：

1. 玩家离线期间持续累计基础收益。
2. 上线时弹出收益结算弹窗。
3. 支持普通领取和广告双倍领取。

### 5.2 激励广告点位

建议首版点位：

1. 离线双倍
2. 主角或主播升级立即完成
3. 直播收益短时加速
4. 带货爆单翻倍
5. 免费招募一次

### 5.3 插屏广告

建议只放在：

1. 章节完成后
2. 自然切页节点
3. 一定在线时长后的返回节点

## 6. 数值原则

1. 不看广告也能玩。
2. 看广告一定有显著收益。
3. 前期广告收益偏强，建立正反馈。
4. 中后期广告价值随收益池扩大而同步提升。

## 7. 页面与交互

涉及弹窗：

1. 离线收益弹窗
2. 双倍奖励弹窗
3. 升级加速弹窗
4. 免费招募弹窗
5. 插屏广告触发节点

交互要求：

1. 广告按钮文案要清楚写明收益。
2. 广告关闭或失败时，不能阻断主流程。
3. 插屏广告触发频率要严格受控。

## 8. 与其他模块的关系

1. 模块 04 承接直播加速。
2. 模块 05 承接爆单翻倍。
3. 模块 07 承接免费招募。
4. 模块 08 可以围绕广告行为设计日常任务。

## 9. MVP 边界

首版只做几种高价值广告场景，不追求广告点位数量最大化。

## 10. 验收标准

1. 广告收益对玩家是明显有吸引力的。
2. 离线收益足够驱动玩家回流。
3. 插屏广告不会在关键沉浸环节打断玩家。
4. 广告系统接入后不破坏整体节奏和留存。
