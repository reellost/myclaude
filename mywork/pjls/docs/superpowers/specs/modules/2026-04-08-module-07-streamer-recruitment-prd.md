# 模块 07：招募主播系统 PRD

## 1. 模块定位

招募主播系统负责把游戏从“我自己直播”扩展到“我开始签别人”，是进入 MCN 阶段后的核心新增乐趣与扩张手段。

## 2. 设计目标

1. 让玩家获得角色收集的乐趣。
2. 让主播招募成为公司扩张最直接的反馈。
3. 不把招募做成重抽卡系统，避免复杂和付费化压力过强。

## 3. 玩家体验目标

玩家应该感受到：

1. 我终于不只是一个人奋斗了。
2. 每招到一个新主播，公司都会更强。
3. 新主播有差异，但不会复杂到看不懂。

## 4. 功能范围

MVP 包含：

1. 主播招募入口
2. 主播基础品质和风格标签
3. 主播上阵与下阵
4. 主播升级
5. 招募后的可视化收集展示

MVP 不包含：

1. 复杂十连抽系统
2. 深度主播羁绊系统
3. 多维技能树
4. 复杂职业克制

## 5. 核心规则

### 5.1 解锁时机

建议在第 3 章后段或第 4 章开启，确保前期先把女主成长做扎实。

### 5.2 主播基础属性

每位主播至少包含：

1. 基础流量产出
2. 带货转化效率
3. 品质
4. 风格标签
5. 可上阵位置

### 5.3 招募方式

首版建议采用简单方式：

1. 金币招募或免费冷却招募
2. 广告补充一次免费招募
3. 章节奖励赠送特定主播

### 5.4 上阵规则

建议：

1. 女主固定上阵
2. 其他主播根据直播位数量上阵
3. 上阵主播自动提供流量与带货加成

## 6. 页面与交互

页面应展示：

1. 当前主播池
2. 已拥有主播列表
3. 主播品质和风格
4. 招募消耗
5. 上阵状态
6. 升级入口

交互要求：

1. 主播信息一眼能看懂强弱差异。
2. 上阵与替换操作尽量简化。
3. 招募成功时必须有强反馈。

## 7. 配置建议

首版建议：

1. 6-10 名可招募主播
2. 2-3 档品质层级
3. 主播差异以数值和人设为主，不做复杂策略搭配

## 8. 与其他模块的关系

1. 由模块 06 解锁开启。
2. 为模块 04 提供额外流量来源。
3. 为模块 05 提供额外带货效率。
4. 为模块 10 提供分享素材和收藏价值。

## 9. MVP 边界

首版只做“招募、上阵、升级、展示”，不做复杂卡池和高深搭配。

## 10. 验收标准

1. 玩家能明显感受到招募后的战力提升。
2. 招募入口不会过早开启，抢走前期主角成长的地位。
3. 主播差异足以支撑收集欲，但不会造成理解负担。
4. 主播系统能稳定支撑第 4-5 章扩张体验。
