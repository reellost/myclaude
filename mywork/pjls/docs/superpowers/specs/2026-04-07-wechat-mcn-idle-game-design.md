# 微信小游戏需求文档：女主播逆袭与 MCN 公司成长模拟经营

## 1. 文档信息

- 文档版本：V1.1
- 文档日期：2026-04-07
- 产品阶段：立项/MVP 需求定义
- 产品类型：微信小游戏
- 核心题材：被辞退女主播逆袭成长，最终打造直播 MCN 公司

## 2. 项目概述

本项目是一款面向微信小游戏生态的轻放置模拟经营游戏。玩家将扮演一位刚被公司辞退的女主播，在失去原有舞台后，被迫开启一段略显腼腆但充满希望的重新开播之旅。她将从简陋房间和零基础直播条件起步，靠一步一步化妆、学习技能、装扮自己、布置直播间，慢慢积累第一批观众和第一桶金。

当女主逐渐摆脱紧张、形成自己的直播风格后，玩家会自然过渡到签约新人、扩建直播间、搭建团队，最终将个人工作室发展为头部直播 MCN 公司。

游戏整体风格以轻松、魔性、女性向为主，强调角色养成的吸引力、房间升级的陪伴感以及公司扩张的成长反馈。产品不追求复杂经营深度，也不追求高操作门槛，而是通过清晰的成长主线、简单的数值闭环和高频的正反馈，适配微信小游戏的碎片化体验与广告变现模式。

## 3. 立项目标

### 3.1 产品目标

1. 做一款用户上手简单、前期几乎无理解门槛的轻经营微信小游戏。
2. 建立一条清晰可感知的成长主线，让玩家始终知道下一步做什么。
3. 用“被辞退女主播重新开播-化妆学习成长-积累流量带货赚钱-做大 MCN 公司”的题材包装轻放置玩法。
4. 适配微信小游戏生态，具备较强的广告变现能力与裂变传播能力。

### 3.2 商业目标

1. 主要收入来源为激励视频广告。
2. 插屏广告作为补充，不打断核心体验。
3. 裂变分享用于提升新增与回流，但不依赖重社交关系链。

## 4. 目标用户

### 4.1 核心用户画像

1. 偏女性向的轻度小游戏用户。
2. 喜欢角色收集、养成反馈、经营成长感的玩家。
3. 习惯 1-3 分钟碎片化体验，接受看广告换成长加速。
4. 对“逆袭成长”“直播养成”“公司变大”题材有轻爽感偏好。

### 4.2 用户需求判断

目标用户更看重以下体验：

1. 进入游戏后很快看懂玩法。
2. 有一个容易代入的女主成长故事。
3. 能不断看到自己和公司一起变强。
4. 有可爱的主播角色可以招募和培养。
5. 不需要复杂操作，也能持续获得成长反馈。
6. 看广告后能明显感觉到变强或变快。

## 5. 产品定位

本产品定位为“轻放置 + 模拟经营 + 女性向逆袭养成”的微信小游戏。

产品核心卖点如下：

1. 题材有辨识度：从被辞退女主播重新出发，一步步做成直播 MCN。
2. 主线足够简单：先养成女主，再扩张公司。
3. 节奏适合微信生态：1-3 分钟即可完成一轮有效成长。
4. 商业化自然：广告点位与加速成长强绑定。
5. 包装有传播性：女主逆袭、主播、公司、收益、公司名片等内容适合分享。

## 6. 核心玩法概述

### 6.1 核心循环

游戏主循环为：

`化妆/学习技能/装扮直播间 -> 开播自动产出流量 -> 流量转化为带货收益 -> 收益用于升级个人形象/直播间/公司 -> 解锁招募功能与新主播 -> 继续扩张`

### 6.2 设计原则

1. 跳舞只是视觉包装和产流手段，不做重操作玩法。
2. 前期先做“女主个人成长”，后期再自然转向“公司扩张”。
3. 所有核心系统都服务于“从个人主播成长为 MCN 公司”的主成长目标。
4. 玩家前期只需要理解三件事：升级自己、开播赚钱、装扮房间。
5. 系统数量控制在最少，避免微信小游戏常见的新手流失问题。

### 6.3 双阶段成长结构

为保证题材代入感与主线清晰度，整体成长拆为两个阶段：

第一阶段：个人主播逆袭期

1. 女主被辞退后重新开播。
2. 通过化妆、学习技能、装扮自己和直播间获得更高流量。
3. 完成从“腼腆新人”到“小有名气主播”的转变。

第二阶段：MCN 扩张期

1. 在女主验证直播模式成功后开放招募功能。
2. 玩家开始签约其他主播并扩建直播间。
3. 从个人工作室成长为完整 MCN 公司。

## 7. 核心系统设计

### 7.1 主角成长系统

女主是前期唯一核心养成对象，承担情绪代入、成长反馈和剧情推进三重作用。

主角成长分为四条轻量成长线：

1. 化妆：提升开播吸引力与基础流量。
2. 直播技能：提升直播表现与带货转化。
3. 穿搭装扮：提升角色魅力值与流量上限。
4. 心态成长：作为剧情包装，体现从腼腆到自信的变化。

设计原则：

1. 所有成长线尽量共用金币或简单材料，不增加复杂货币。
2. 每个成长点都要直接反馈到流量或带货效率。
3. 表现上突出“变美、变自信、变专业”的正反馈。

主角成长承担的产品职责：

1. 完成开局剧情代入。
2. 支撑前期 1-2 章节的主要成长。
3. 为后续扩张 MCN 提供情绪上的升级感。

### 7.2 直播间装扮系统

直播间是前期最重要的环境成长模块，与女主成长并行。

直播间升级内容建议拆成四类：

1. 基础设备：手机、补光灯、麦克风、摄像头。
2. 房间布置：背景墙、地毯、桌椅、装饰物。
3. 氛围包装：灯效、贴纸、主题风格。
4. 功能设备：货架、展示台、物流台等带货相关设施。

直播间系统的核心作用：

1. 作为“看得见的成长”载体。
2. 直接提升流量效率和带货效率。
3. 为女性向用户提供轻装修和装扮满足感。

注意事项：

1. 首版只做轻量升级，不做高自由度装修编辑器。
2. 装扮结果以阶段解锁和部件替换为主，控制开发成本。

### 7.3 招募主播系统

当女主达到指定章节后，解锁签约主播功能，游戏从个人成长自然过渡到 MCN 扩张。

每位主播具备以下基础属性：

1. 基础流量产出
2. 带货转化效率
3. 等级
4. 品质
5. 风格标签

主播系统设计原则：

1. 前期不引入复杂职业克制。
2. 前期不做复杂技能搭配。
3. 差异化主要通过人设、外观、品质和产出效率体现。

主播成长方式：

1. 招募获得主播。
2. 使用金币升级主播。
3. 达成条件后进行升星或晋级。
4. 解锁外观、动作、称号等表现内容。

主播系统承担的产品职责：

1. 提供角色收集乐趣。
2. 承担中后期成长反馈。
3. 支撑分享与裂变的晒图内容。

### 7.4 公司系统

公司系统是本项目的后期核心成长主线。

主要成长模块包括：

1. 办公室等级。
2. 直播间数量。
3. 直播间等级。
4. 运营团队等级。
5. 选品能力等级。

玩家感知到的成长路径如下：

1. 从小工作室起步，只能围绕女主个人直播展开。
2. 升级公司后开放更多直播间。
3. 直播间越多，同时在线产流的主播越多。
4. 运营和选品越强，流量转收入效率越高。
5. 最终成长为头部直播机构。

公司系统的核心价值是让玩家持续感受到“公司越来越大”，这是本产品最重要的长期驱动力。

### 7.5 流量系统

流量是最核心的中间资源，负责把“直播成长”与“公司赚钱”连接起来。

设计规则：

1. 女主和主播自动直播，持续产出流量。
2. 流量进入公司总池。
3. 流量不直接变金币，而是进入带货转化环节。

流量主要受以下因素影响：

1. 主角成长等级。
2. 主播等级和品质。
3. 直播间等级。
4. 公司运营加成。
5. 广告或临时 Buff 加速。

流量系统的表现重点：

1. 数值上涨要直观。
2. 演出反馈要轻快。
3. 玩家不用手动干预，也能持续感受到增长。

### 7.6 带货系统

带货系统负责将流量转化为金币收益。

基础逻辑：

1. 每个阶段开放 1-3 个商品位。
2. 玩家选择当前主推商品。
3. 系统根据流量、商品转化率、商品利润自动结算收益。

玩家在带货系统中的决策点保持极简：

1. 当前主推哪个商品。
2. 是否升级商品位。
3. 是否解锁更高价值商品。

带货系统的作用：

1. 提供“赚钱”反馈。
2. 增强经营感。
3. 为广告点位提供合理挂钩场景，例如爆单翻倍、加速带货等。

### 7.7 主线推进系统

整体采用章节式成长结构，每章代表主角和公司发展的一个阶段。

建议章节示例：

1. 被辞退后的出租屋重启。
2. 腼腆新人的第一间像样直播房。
3. 小有名气的个人工作室。
4. 初具规模的主播团队。
5. 本地热门 MCN 机构。

每章推进目标统一为简单任务组合：

1. 主角达到指定成长等级。
2. 直播间达到指定装扮等级。
3. 公司达到指定等级。
4. 招募指定数量主播。
5. 累计获得指定流量。
6. 完成指定带货销售额。

这样可以保证玩家始终明确下一步目标，降低流失风险。

## 8. 新手体验设计

### 8.1 新手体验目标

在 60 秒内让玩家理解核心闭环，并接受“女主重新出发”的情绪背景：

`升级自己 -> 开播产流 -> 带货赚钱 -> 装扮房间 -> 再次成长`

### 8.2 新手流程建议

1. 开场短剧情交代“女主被辞退，只能自己重新开播”。
2. 引导玩家完成第一次简单化妆或穿搭升级。
3. 引导玩家布置最基础的直播角落。
4. 引导玩家点击开播。
5. 女主自动直播并产出第一波流量。
6. 引导玩家选择首个带货商品。
7. 玩家获得第一笔收益。
8. 引导升级主角技能或直播间。
9. 引导体验首次广告加速或双倍奖励。

### 8.3 新手期原则

1. 不一次性讲完全部系统。
2. 先给收益反馈，再讲成长逻辑。
3. 第一轮广告体验必须收益明显。
4. 新手阶段尽量只保留单路径点击。

## 9. 数值闭环设计

### 9.1 MVP 资源结构

首版建议采用“两资源一目标”结构：

1. 流量：由主角和主播自动产出。
2. 金币：由流量带货转化获得。
3. 公司等级：作为解锁与章节推进门槛。

### 9.2 基础闭环

`提升主角/直播间 -> 流量增加 -> 带货收入提高 -> 金币增加 -> 解锁招募与公司升级 -> 扩张主播团队 -> 再次提升流量`

### 9.3 数值设计原则

1. 前期成长节奏快，保证首局爽感。
2. 中期节奏适度放缓，让广告加速有价值。
3. 不引入过多货币，避免认知负担。
4. 不让玩家陷入长时间纯等待。

### 9.4 节奏目标

1. 前 3 分钟内玩家应经历多次升级。
2. 前 30 分钟内玩家应明显看到个人和直播间变化。
3. 每次回流上线都应能拿到离线收益并推动至少一次成长。

## 10. 广告变现设计

### 10.1 商业化原则

1. 广告服务于成长加速，而不是打断核心体验。
2. 不看广告也能推进，看广告只是更快。
3. 激励广告收益必须足够明显，建立“值得点”的预期。
4. 插屏广告只出现在低打扰节点。

### 10.2 激励视频广告点位

建议首版接入以下点位：

1. 离线收益双倍领取。
2. 主角或主播升级立即完成。
3. 直播间收益加速。
4. 带货爆单收益翻倍。
5. 免费招募一次主播。
6. 章节目标奖励翻倍。

### 10.3 插屏广告点位

建议谨慎投放在以下节点：

1. 章节完成后。
2. 主界面自然切页节点。
3. 一定在线时长后的退出或返回节点。

### 10.4 广告与数值结合方式

1. 前期广告收益偏强，帮助用户建立正反馈。
2. 中后期广告收益与更高等级收益池绑定。
3. 重点广告场景围绕“翻倍”“加速”“立即完成”“免费招募”。

## 11. 裂变与分享设计

### 11.1 裂变目标

1. 利用微信小游戏社交生态获取新增。
2. 用助力和晒图机制促进回流。
3. 让分享行为看起来像成长的一部分，而不是硬性任务。

### 11.2 建议裂变玩法

1. 邀请助力获得限定主播或限定外观。
2. 分享缩短主播招募等待时间。
3. 好友助力后获得宣传流量包。
4. 生成逆袭成长海报，展示妆容阶段、直播间等级、今日销售额。
5. 生成轻量排行榜内容，例如“本周 MCN 新星”。

### 11.3 传播内容方向

更适合被分享的内容包括：

1. 搞笑或有个性的公司名字。
2. 女主从素人到人气主播的变化。
3. 签约到的新主播。
4. 今天赚到的收益。
5. 直播间从简陋角落升级为精致空间的变化。

## 12. 微信小游戏适配原则

1. 单次游玩时长控制在 1-3 分钟。
2. 离线收益必须明显，支持回流。
3. 主界面尽量单层或浅层，避免复杂菜单。
4. 每次上线都给玩家一个明确的小目标。
5. 操作以点击和领取为主，不引入复杂节奏玩法。
6. 故事演出尽量短，避免大量剧情文本打断节奏。

## 13. MVP 范围定义

### 13.1 MVP 应包含内容

1. 1 名可持续成长的主角主播。
2. 1 个主直播间场景，可分阶段升级外观。
3. 6-10 名可招募主播。
4. 5 个成长章节，覆盖“个人逆袭”到“MCN 起步”。
5. 3 类基础商品赛道。
6. 主角成长、直播间升级、主播招募、公司升级四条成长线。
7. 离线收益功能。
8. 激励广告与基础插屏广告。
9. 基础分享助力功能。
10. 章节目标与基础任务系统。

### 13.2 MVP 不建议包含内容

1. 复杂剧情分支。
2. 多种经营货币。
3. PvP 玩法。
4. 重竞技排行榜。
5. 复杂主播技能搭配。
6. 多城市扩张。
7. 高自由度装修编辑器和深度换装系统。

MVP 的首要任务是验证玩法成立、题材点击率、首日留存和广告收益，而不是一次性堆满内容。

## 14. 功能拆解建议

### 14.1 P0 核心功能

这一层是首版必须完成的基础骨架：

1. 开场剧情功能：完成“被辞退-重新开播”的短故事演出。
2. 主角成长功能：化妆、技能、穿搭三条轻成长入口。
3. 直播间成长功能：设备升级、房间阶段变化。
4. 开播产流功能：自动直播、自动产出流量。
5. 带货收益功能：商品选择、收益结算、订单表现。
6. 公司成长功能：章节推进、公司等级、招募解锁。
7. 招募主播功能：主播获取、主播升级、主播上阵。
8. 任务目标功能：章节任务、日常目标、奖励发放。
9. 广告功能：离线双倍、加速、免费招募、爆单翻倍。
10. 分享助力功能：基础分享、助力奖励、成长海报。

### 14.2 P0 主要页面拆解

从交互层看，首版建议最少包含以下页面：

1. 开场剧情页。
2. 主直播间主页。
3. 主角成长页。
4. 直播间升级页。
5. 商品带货页。
6. 招募主播页。
7. 公司成长页。
8. 任务奖励页。
9. 广告领奖弹窗。
10. 分享助力弹窗。

### 14.3 P1 增强功能

这部分建议在首版验证后补充：

1. 更多妆容和穿搭表现。
2. 更多直播间主题风格。
3. 更丰富的主播人设差异。
4. 限时活动与签到体系。
5. 更完整的分享模板和排行榜展示。

### 14.4 功能分工建议

如果后续要给团队拆分，可以先按以下方向拆：

1. 策划：主线章节、数值闭环、任务配置、广告收益配置。
2. 美术：女主形象成长、主播角色、直播间阶段外观、UI 包装。
3. 程序：主循环、收益结算、升级系统、广告接入、分享接入。
4. 运营：活动节奏、裂变包装、广告策略、素材测试。

## 16. 成功指标建议

立项阶段建议优先关注以下指标：

1. D1 留存达到 30%-35% 以上。
2. 单日人均激励视频次数达到 4-8 次。
3. 单次会话时长稳定在 1-3 分钟。
4. 首日玩家可顺利完成 2-3 个章节目标。
5. 分享或助力功能有实际使用率。

## 17. 风险与控制建议

### 17.1 主要风险

1. 题材虽有辨识度，但若“被辞退”开场过重，会削弱轻松感。
2. 纯放置体验若反馈不足，可能导致前期无聊。
3. 广告点位如果收益不够强，会影响商业化效率。
4. 主角成长、房间成长、公司成长若同时铺开，容易显得系统过多。

### 17.2 控制建议

1. 开场剧情控制在极短长度，用轻喜剧包装失业背景。
2. 首版聚焦单主线，不扩展复杂支线系统。
3. 强化主角演出、房间变化、数值跳动、公司升级的视觉反馈。
4. 广告收益设计为明显可感知的翻倍或加速。
5. 用章节目标替代复杂系统教学，持续给玩家短期目标。

## 18. 结论

本项目最适合做成一款以前期“女主播逆袭成长”为核心、以后期“MCN 公司扩张”为核心、以“广告加速成长”为主要商业化方式的轻放置微信小游戏。

首版重点不在于做复杂，而在于把以下四件事做扎实：

1. 上手简单。
2. 主线清晰。
3. 反馈够爽。
4. 广告自然。

只要首版能把“女主成长、直播起量、带货赚钱、招募扩张”这一闭环跑顺，就具备继续扩充角色、活动、裂变与商业化的空间。
