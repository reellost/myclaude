# 直播间系统

## 1. 系统定位

直播间系统是本项目的内容骨架。首版不做大量房型，而是明确三种核心直播间，并为每种直播间绑定一种固定热场交互。

系统原则：

`一个直播间 = 一个内容定位 = 一个主要产出方向 = 一个固定热场交互`

## 2. 三类核心直播间

### 2.1 美妆陪伴直播间

定位：起步房间、养盘房间。

主要作用：

1. 稳定产出热度。
2. 承接女主前期成长。
3. 提供早期礼物打赏收益。

固定热场交互：

`三连上镜`

### 2.2 跳舞直播间

定位：起量房间、聚消费力房间。

主要作用：

1. 通过热场和表现力吸引高价值观众。
2. 把已有热度转成消费力。
3. 制造内容爆点。

固定热场交互：

`连点热舞`

### 2.3 带货直播间

定位：变现房间。

主要作用：

1. 消耗热度和消费力。
2. 产出主要金币收益。
3. 承接公司现金流。

固定热场交互：

`滑动展示与强推`

## 3. 直播间关系

三类直播间不是纯替换关系，也不是一开始全部并行。

建议结构：

1. 前期按阶段成长解锁。
2. 中后期进入共存运营。

推荐节奏：

1. 第 1 章：美妆陪伴直播间。
2. 第 2 章：解锁跳舞直播间。
3. 第 3 章：解锁带货直播间。
4. 第 4 章起：三类直播间开始共存。

## 4. 直播间席位

公司升级负责解锁更多直播间席位。

席位的意义：

1. 决定公司能同时运营多少个房间。
2. 决定玩家如何配置“养盘、起量、变现”结构。
3. 承接后期主播投放和房间配比。

## 5. 热场交互通用规则

所有直播间热场交互都遵循以下规则：

1. 单次时长控制在 5-8 秒。
2. 不做强失败判定。
3. 交互结果分为普通、优秀、完美。
4. 奖励统一表现为短时房间 Buff。

## 6. 房间成长方向

首版每种直播间都允许做轻量升级，但升级目标不同：

1. 美妆陪伴直播间：提升热度稳定性与上镜质感。
2. 跳舞直播间：提升消费力聚合效率与爆发幅度。
3. 带货直播间：提升转化效率与商品承载能力。

## 7. 房间配比原则

为了避免玩家只堆单一房间，后期经营建议遵循：

1. 美妆陪伴间负责养基本盘。
2. 跳舞间负责放大高价值观众。
3. 带货间负责吃资源换金币。

带货间数量不得长期脱离前两者支撑，否则金币效率应明显下降。

## 8. 玩家体验目标

直播间系统要给玩家的感受是：

1. 我不是只有一个背景板，而是在做不同内容间的经营取舍。
2. 每解锁一个房间，就多一个新的小爽点。
3. 后期公司像一个内容矩阵，而不是单房间无限升级。

## 9. 与其他系统的关系

1. 与主角成长系统 共同定义前期成长路线。
2. 与热度与消费力系统 共同定义三类房间的产出职责。
3. 与主播系统 共同定义后期的主播投放。
4. 与带货收益系统 共同决定金币主循环。
