# 公司成长与章节推进系统

## 1. 系统定位

公司成长与章节推进系统负责把“女主重新开播”逐步拉成“MCN 公司成型”的长期结构。

公司不是无尽核心，而是：

1. 解锁新系统。
2. 解锁更多席位。
3. 推动章节阶段变化。
4. 承接从个人直播到多房间经营的扩张感。

## 2. 公司成长职责

公司成长主要解决四个问题：

1. 什么时候开新房间。
2. 什么时候能招更多主播。
3. 什么时候进入多房间共存阶段。
4. 什么时候解锁 PK 等后期玩法。

## 3. 章节节奏建议

### 第 1 章：重新开播

1. 只开放美妆陪伴直播间。
2. 重点在女主成长和房间起步。

### 第 2 章：开始起量

1. 解锁跳舞直播间。
2. 首次正式引入消费力概念。

### 第 3 章：开始变现

1. 解锁带货直播间。
2. 解锁主播签约。
3. 形成三房间最小经营闭环。

### 第 4 章：内容矩阵成型

1. 开始多房间并行。
2. 开始强调主播投放与房间配比。

### 第 5 章：MCN 初具规模

1. 进一步扩房。
2. 解锁 PK 与名望玩法。
3. 公司进入长期经营阶段。

## 4. 公司等级作用

公司等级主要影响：

1. 直播间席位数量。
2. 招募池开放。
3. 高级功能解锁。
4. 章节门槛推进。

## 5. 主要消耗

公司成长统一消耗金币，不额外引入办公室材料或装修许可证等资源。

## 6. 系统边界

公司成长不负责：

1. 无限数值拉长。
2. 复杂人事管理。
3. 房租、工资、税费等真实经营负担。

这些内容可以保留题材包装，但不进入首版真实扣费逻辑。

## 7. 玩家体验目标

玩家在公司成长上要感受到：

1. 我不再只是在养一个人。
2. 我的内容线越来越完整。
3. 每次公司升级都带来新的经营空间。

## 8. 与其他系统的关系

1. 与直播间系统 共同决定房间解锁顺序。
2. 与主播系统 共同决定公司后期矩阵厚度。
3. 与 PK直播间与名望系统 共同承接后期成长。
4. 与任务与活动系统 共同引导玩家按阶段理解新玩法。
