# 资源系统总表

## 1. 文档定位

本文档用于统一当前版本所有核心资源口径，回答以下问题：

1. 当前版本到底有哪些资源。
2. 哪些是主货币，哪些是上游经营资源，哪些是成长或展示资源。
3. 每种资源如何产出、如何消耗。
4. 哪些资源不应进入首版。

## 2. 总体资源原则

首版资源体系必须保持小游戏级别的轻量。

正式采用的核心资源结构为：

`热度 -> 消费力 -> 金币`

并辅以：

1. 公司等级与章节进度作为门槛资源。
2. 主播名望与主播身价作为长期成长与展示资源。
3. PK积分与荣誉币作为后期轻竞技资源。

## 3. 资源总表

| 资源名 | 类型 | 主要产出 | 主要消耗 | 主要用途 |
| --- | --- | --- | --- | --- |
| 金币 | 主货币 | 礼物收益、带货成交、任务、离线 | 主角成长、房间成长、公司升级、主播招募、主播培养、PK投入 | 承担全部主要消费 |
| 热度 | 上游经营资源 | 美妆陪伴直播间、热场互动、活动奖励 | 跳舞直播间部分消耗、带货直播间消耗 | 表示关注规模，是后续经营前置条件 |
| 消费力 | 上游经营资源 | 跳舞直播间、美妆沉淀、活动奖励 | 带货直播间消耗 | 表示高价值观众意愿 |
| 公司等级 | 门槛资源 | 金币升级公司 | 不二次消耗 | 解锁席位、功能、章节 |
| 章节进度 | 门槛资源 | 完成章节目标 | 不二次消耗 | 控制阶段展开 |
| 主播名望 | 长期成长资源 | PK胜利、活动、重点运营 | 不主动消耗 | 提升主播知名度与身价 |
| 主播身价 | 派生展示值 | 由品质、等级、名望共同决定 | 不主动消耗 | 用于展示主播价值与长期追求 |
| 状态 | 主播运行状态 | 时间恢复、道具恢复、活动恢复 | PK、连续高强度运营 | 限制单主播无脑使用 |
| PK积分 | 竞技资源 | PK胜利 | 排名结算 | PK 排名与展示 |
| 荣誉币 | 专属轻货币 | PK奖励 | 外观、称号、保护券兑换 | PK系统奖励承载 |
| 免费招募次数 | 功能权益 | 广告、分享、活动 | 使用后清空 | 降低收集门槛 |

## 4. 不引入资源

首版明确不做：

1. 钻石
2. 体力
3. 工资扣费货币
4. 主播碎片树
5. 多种活动代币并行

## 5. 资源关系

### 5.1 早期循环

`美妆间产热度 -> 热度转礼物金币 -> 金币升级女主和房间`

### 5.2 中期循环

`美妆间产热度 -> 跳舞间聚消费力 -> 带货间消耗两者转金币`

### 5.3 后期循环

`经营赚金币 -> 招募和培养主播 -> PK 提升名望 -> 主播更值钱 -> 继续经营与投放`

## 6. 金币用途

金币后期的主要作用不是缴费，而是投资：

1. 养主角。
2. 升房间。
3. 升公司。
4. 招主播。
5. 养主播。
6. 做 PK 培训、恢复与续约。

## 7. 玩家体验目标

玩家应该能清楚理解：

1. 热度代表“有人看”。
2. 消费力代表“有人愿意花”。
3. 金币代表“公司能继续投”。
4. 名望代表“主播真的打出名气了”。

## 8. 与其他系统的关系

1. 为热度与消费力系统 提供核心定义。
2. 为带货收益系统 提供金币口径。
3. 为主播系统、PK系统 提供长期成长资源口径。
4. 为所有功能需求文档提供统一资源语言。
