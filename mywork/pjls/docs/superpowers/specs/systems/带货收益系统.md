# 带货收益系统

## 1. 系统定位

带货收益系统负责把前置经营成果转成金币，是公司现金流的核心来源。

系统必须同时满足两件事：

1. 前期也能有基础收益，不会卡死。
2. 中后期的主要金币来源必须来自带货直播间。

## 2. 收益阶段划分

### 2.1 前期收益

前 1-2 章，玩家尚未进入成熟带货阶段，因此允许：

`热度 -> 礼物打赏金币`

这部分收益用于支撑女主和美妆陪伴直播间的起步升级。

### 2.2 中后期收益

带货直播间解锁后，主收益切换为：

`热度 + 消费力 -> 带货成交额 -> 金币`

## 3. 带货房间职责

带货直播间不负责养流量，不负责聚高价值观众，它只负责：

1. 吃掉已有热度。
2. 吃掉已有消费力。
3. 把两者变成金币与成交额。

## 4. 商品结构

首版商品结构保持轻量：

1. 低门槛引流商品。
2. 中段稳定成交商品。
3. 高价值冲榜商品。

玩家操作只保留两个轻决策：

1. 当前主推哪种商品。
2. 是否升级商品位或解锁更高层商品。

## 5. 核心公式口径

建议首版使用以下口径：

`成交额 = 带货基础值 x 带货主播系数 x 商品系数 x 热度利用率 x 消费力利用率`

`金币 = 成交额 x 结算系数`

解释：

1. 热度不够，卖不大。
2. 消费力不够，卖不贵。
3. 主播与房间适配差，变现效率下降。

## 6. 热场交互

带货直播间固定热场交互为：

`滑动展示与强推`

玩法目标：

1. 让玩家在变现节点有一层参与感。
2. 让“强推”“对比”“限时感”更夸张。
3. 为本轮成交提供短时爆发 Buff。

## 7. 金币用途

金币主要回流到：

1. 主角成长。
2. 直播间升级。
3. 公司升级。
4. 主播招募。
5. 主播培养。
6. PK 系统中的培训、续约和恢复。

## 8. 系统边界

首版不做：

1. 仓储系统。
2. 退货损耗系统。
3. 税费系统。
4. 复杂供应链。

这些题材表达可以出现在文案里，但不应成为真实扣费系统。

## 9. 玩家体验目标

1. 前期能感受到“虽然还不会带货，但已经能赚到第一笔钱”。
2. 中期开始理解“经营前置资源是为了带货吃满”。
3. 后期能感受到“房间配比和主播投放真的会影响赚钱效率”。

## 10. 与其他系统的关系

1. 与热度与消费力系统 共同构成金币主闭环。
2. 与主播系统 共同决定带货房间效率。
3. 与公司成长与章节推进系统 共同承接中后期扩张。
4. 与资源系统总表 共同定义金币主货币地位。
