# 开场剧情与新手引导

## 1. 系统定位

开场剧情与新手引导负责建立玩家对女主、直播事业和三类直播间成长路线的第一印象。

首版目标不是讲长剧情，而是在最短时间里让玩家理解三件事：

1. 女主是一名被辞退、状态低落但仍想重新开始的前主播。
2. 玩家当前正在帮她从一个人重新站起来。
3. 游戏主循环是“开播热场 -> 积累热度/礼物 -> 赚金币 -> 升级主角与房间 -> 解锁新直播间和新主播”。

## 2. 剧情起点

女主原本是某家 MCN 旗下的小主播，因为表现平平、缺少资源、又不会主动争取，被公司裁掉。离开公司后，她只能在简陋出租屋里重新开播。

她的起步状态应体现为：

1. 腼腆，不太敢看镜头。
2. 妆造普通，直播空间简陋。
3. 一开始没有团队、没有成熟带货能力。
4. 只能从最轻量、最安全的“美妆陪伴直播间”重新起步。

## 3. 新手阶段的目标

新手引导阶段只做一件事：

`让玩家相信自己真的在把她一点点带起来。`

因此前 10 分钟必须连续给到：

1. 角色状态变好。
2. 直播间变像样。
3. 热场互动有效。
4. 热度增长可见。
5. 金币开始回流。
6. 下一个目标始终明确。

## 4. 首个可玩房间

女主的起步直播间固定为：

`美妆陪伴直播间`

选择它作为起步房间的原因：

1. 最符合“腼腆重新开播”的叙事。
2. 最容易承接化妆、穿搭、打光、上镜这些前期成长线。
3. 不要求女主一开始就具备强烈表现力或成熟销售力。
4. 它能自然过渡到后续的跳舞直播间和带货直播间。

## 5. 新手闭环

首版新手闭环应拆成以下 6 步：

1. 进入剧情开场，看到女主重新开播的决心。
2. 引导玩家完成第一次热场互动。
3. 玩家看到热度开始上涨。
4. 热度自动转成早期礼物收益，获得第一笔金币。
5. 玩家升级主角或房间。
6. 玩家看到第二次开播明显更顺，形成“点了就更好”的认知。

## 6. 早期收益说明

为了保证在只解锁美妆陪伴直播间时也能跑通循环，前 1-2 章允许：

`热度 -> 礼物打赏金币`

这是一条早期过渡收益线，用于支撑玩家完成主角和房间的起步升级。

当跳舞直播间和带货直播间解锁后，主经济重心逐步转向：

`热度 -> 消费力 -> 带货金币`

## 7. 首个热场交互

新手期固定热场交互为：

`三连上镜`

表现流程：

1. 点击补妆。
2. 点击打光。
3. 点击摆 pose。

完成后给予一次短时“上镜状态”加成，直接提高本轮热度获取效率。

设计要求：

1. 3 秒内看懂。
2. 5-8 秒内结束。
3. 不做失败判定。
4. 至少有普通、优秀、完美三档表现反馈。

## 8. 新手引导节奏

### 8.1 前 2 分钟

目标：建立“我点一下，她就变更好”的感觉。

重点展示：

1. 主角变化。
2. 热场交互。
3. 热度上涨。
4. 第一笔金币到账。

### 8.2 第 3-5 分钟

目标：让玩家开始主动找下一个升级点。

重点展示：

1. 化妆升级。
2. 房间布置升级。
3. 新手任务奖励。

### 8.3 第 5-10 分钟

目标：埋下“未来会从一个人变成一家公司”的预期。

重点展示：

1. 直播间更像样。
2. 女主更敢出镜。
3. 章节目标开始指向下一个直播间与公司成长。

## 9. 广告与引导边界

新手阶段不允许广告打断第一次完整闭环。

建议规则：

1. 前 2 分钟不出强广告。
2. 第一次热场完成前不弹插屏。
3. 第一次收益到账后，才允许出现弱提示型激励广告。

## 10. 与其他系统的关系

1. 为主角成长系统 提供第一阶段情绪基础。
2. 为直播间系统 锚定首个可玩房间。
3. 为热度与消费力系统 提供最早期的热度来源。
4. 为公司成长与章节推进系统 建立长期扩张目标。
