# 广告与离线收益系统

## 1. 系统定位

广告与离线收益系统负责把微信小游戏的商业化能力挂在已有经营循环之上，而不是单独创造一套新经济。

原则：

1. 广告是补速器。
2. 离线是回流奖励。
3. 不用广告也能推进。
4. 广告不能打断第一次完整体验。

## 2. 广告类型

### 2.1 离线双倍

作用：放大离线金币收益。

### 2.2 美妆热度加速

作用：短时提高美妆陪伴直播间热度产出。

### 2.3 跳舞消费力爆发

作用：短时提高跳舞直播间消费力聚合效率。

### 2.4 带货爆单加成

作用：短时提高带货直播间成交效率。

### 2.5 免费招募

作用：降低主播收集门槛。

## 3. 离线收益规则

离线收益统一折算为金币。

表现逻辑：

1. 根据离线前的主经营状态估算金币收益。
2. 回流时允许看广告双倍领取。
3. 不对离线期间的 PK、状态和名望做复杂补算。

## 4. 广告露出原则

1. 首次完整闭环前不出强广告。
2. 强广告必须挂在明确成长节点上。
3. 不允许多个强广告连续强推。
4. 广告描述必须直接说明收益结果。

## 5. 与当前循环的挂法

1. 美妆热度加速：帮助前期热度更快起盘。
2. 跳舞消费力爆发：帮助中期更快聚高价值观众。
3. 带货爆单：帮助后期快速把资源换成金币。
4. 免费招募：帮助主播池更快扩充。
5. 离线双倍：帮助回流补足一段经营落差。

## 6. 不建议做的内容

1. 强制看广告续命。
2. 广告后才能继续直播。
3. 把广告做成主金币来源。
4. 用广告替代全部成长。

## 7. 玩家体验目标

1. 玩家愿意主动看广告，因为它确实有效。
2. 玩家不会觉得广告在抢主玩法。
3. 离线回流有惊喜，但不会压过主动经营。

## 8. 与其他系统的关系

1. 与热度与消费力系统 共同定义短时爆发点。
2. 与带货收益系统 共同定义金币放大量。
3. 与主播系统 共同定义免费招募价值。
4. 与任务与活动系统 共同支撑回流节奏。
