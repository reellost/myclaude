# 任务与活动系统

## 1. 系统定位

任务与活动系统负责给玩家持续提供明确目标，避免在多系统展开后失去方向。

首版任务系统应服务于：

1. 新手引导。
2. 阶段成长。
3. 日常回流。
4. 后期 PK 与主播运营。

## 2. 任务分类

### 2.1 章节任务

作用：推动主线阶段和系统理解。

重点目标：

1. 主角成长。
2. 房间成长。
3. 热度累计。
4. 金币累计。
5. 新房间解锁。

### 2.2 日常任务

作用：支撑回流和短会话。

重点目标：

1. 完成热场互动。
2. 完成指定次数直播。
3. 完成带货收益目标。
4. 完成一次 PK 或培养行为。

### 2.3 周活动

作用：承接后期内容与竞争氛围。

重点方向：

1. 周 PK 活动。
2. 周主播名望冲刺。
3. 周房间配比挑战。

## 3. 奖励设计

任务奖励应保持简单，优先发放：

1. 金币。
2. 热度包。
3. 免费招募次数。
4. 状态恢复道具。
5. 名望增益或荣誉币。

不建议发大量独立活动代币。

## 4. 引导原则

任务系统必须帮玩家回答“我现在最该做什么”。

具体要求：

1. 前期引导优先指向女主与首个房间。
2. 跳舞直播间解锁时任务应主动引导玩家理解消费力。
3. 带货直播间解锁时任务应引导玩家理解资源消耗与变现。
4. PK 解锁后，任务应引导玩家接触名望和状态管理。

## 5. 活动原则

周活动建议围绕已有系统做放大，不额外发明新规则：

1. 热场表现加成周。
2. 带货爆单周。
3. 名望冲刺周。
4. 主播签约周。

## 6. 玩家体验目标

1. 玩家任何时候上线都知道下一步目标。
2. 任务不是负担，而是节奏指引。
3. 活动是对现有循环的放大，不是新的复杂系统。

## 7. 与其他系统的关系

1. 与开场剧情与新手引导 共同构成前 10 分钟目标链。
2. 与公司成长与章节推进系统 共同推进阶段解锁。
3. 与主播系统、PK系统 共同承接中后期留存内容。
4. 与广告与离线收益系统 共同支撑回流节奏。
