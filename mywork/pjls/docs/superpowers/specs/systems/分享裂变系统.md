# 分享裂变系统

## 1. 系统定位

分享裂变系统负责把玩家在直播经营中的可炫耀结果包装成微信小游戏适合传播的内容。

分享不是单独玩法，而是为现有系统提供：

1. 展示感。
2. 助力感。
3. 短时补速。

## 2. 核心分享点

### 2.1 女主成长海报

内容：

1. 女主当前阶段形象。
2. 当前主打直播间。
3. 当前公司名字或阶段。

### 2.2 头部主播名片

内容：

1. 主播品质。
2. 主播名望。
3. 当前所在直播间。

### 2.3 带货战报

内容：

1. 本场成交额。
2. 当前爆款商品。
3. 公司阶段或排名。

### 2.4 PK 胜利海报

内容：

1. 本次 PK 结果。
2. 参战主播。
3. 当前名望提升或积分变化。

## 3. 分享奖励原则

分享奖励必须与当前经营循环直接相关。

建议奖励：

1. 热度包。
2. 免费招募次数。
3. 状态恢复。
4. 等待跳过。

不建议发复杂礼包货币。

## 4. 助力逻辑

助力更适合用在：

1. 招募主播。
2. 恢复主播状态。
3. 触发短时热场加成。

## 5. 玩家体验目标

1. 分享内容看起来值得晒。
2. 分享奖励拿到手后立刻有用。
3. 分享行为不会脱离主循环。

## 6. 与其他系统的关系

1. 与主角成长系统 共同提供形象展示内容。
2. 与主播系统 共同提供长期炫耀对象。
3. 与带货收益系统、PK系统 共同提供高光时刻。
4. 与资源系统总表 共同定义分享奖励边界。
