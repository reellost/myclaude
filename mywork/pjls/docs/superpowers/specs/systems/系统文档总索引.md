## 3. 当前版本的核心设计变化

1. 主直播间明确收敛为美妆陪伴、跳舞、带货三类。
2. 核心上游资源收敛为热度与消费力。
3. 主播系统改为轻属性 + 房间适配，不再设计重属性树。
4. 后期长期内容由 PK直播间与名望系统承接。
5. 金币继续作为唯一主货币，不引入钻石与工资扣费逻辑。
