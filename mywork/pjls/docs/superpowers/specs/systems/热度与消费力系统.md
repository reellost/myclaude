# 热度与消费力系统

## 1. 系统定位

热度与消费力系统是首版经营循环的上游资源系统，用来拆开“有人看”和“有人愿意花钱”这两件事。

当前版本正式定义两种核心上游资源：

1. `热度`：代表关注度、活跃度和观看规模。
2. `消费力`：代表高价值观众意愿，对外包装可使用“大哥财力”文案。

## 2. 系统目标

1. 让三类直播间形成明确分工。
2. 避免所有房间都只做同一种产出。
3. 为带货变现提供更清晰的前置条件。
4. 在不引入复杂多货币的前提下做出经营配比感。

## 3. 热度的定义

热度代表：

1. 当前直播间有多少人在看。
2. 内容是否有话题、有氛围。
3. 后续跳舞间与带货间是否有足够人群基础。

主要来源：

1. 美妆陪伴直播间稳定产出。
2. 热场互动后的短时爆发。
3. 主角成长和房间升级加成。
4. 部分活动、任务和分享奖励。

## 4. 消费力的定义

消费力代表：

1. 当前观众里有多少高价值付费意愿。
2. 当前这波流量有没有能力支撑更高成交。
3. 带货直播间能否打出高效变现。

主要来源：

1. 跳舞直播间聚合。
2. 热场互动后的短时爆发。
3. 少量由美妆陪伴直播间沉淀。

## 5. 三类房间与资源关系

### 5.1 美妆陪伴直播间

主要职责：

1. 产热度。
2. 维持稳定观看规模。
3. 提供早期礼物打赏收益。

### 5.2 跳舞直播间

主要职责：

1. 聚合消费力。
2. 利用已有热度把高价值观众筛出来。
3. 允许在产消费力时消耗一部分热度。

### 5.3 带货直播间

主要职责：

1. 消耗热度。
2. 消耗消费力。
3. 转化成金币与成交额。

## 6. 资源循环

首版建议统一按以下逻辑理解：

`美妆间养热度 -> 跳舞间把热度转成消费力 -> 带货间消耗热度和消费力变成金币`

## 7. 简化公式口径

### 7.1 热度净变化

`热度净变化 = 美妆产热 + 热场爆发 - 跳舞消耗热度 - 带货消耗热度`

### 7.2 消费力净变化

`消费力净变化 = 跳舞产消费力 + 小额沉淀 - 带货消耗消费力`

### 7.3 早期礼物收益

`礼物金币 = 热度 x 礼物系数`

说明：只在前期和低复杂度阶段承担基础现金流作用。

## 8. 显示规则

为了降低小游戏学习成本，资源显示需要分阶段开放：

1. 第 1 章优先显示热度与金币。
2. 第 2 章跳舞直播间解锁后，再正式显示消费力。
3. 第 3 章带货直播间解锁后，强调“热度 + 消费力 = 成交”。

## 9. 热场交互奖励挂法

热场交互不直接发明新资源，只做短时加成：

1. 美妆陪伴间：短时热度加成。
2. 跳舞间：短时消费力加成。
3. 带货间：短时成交效率加成。

## 10. 玩家体验目标

玩家要能直观理解：

1. 有人看，不等于能赚钱。
2. 跳舞不是直接赚钱，而是在聚更值钱的人。
3. 带货要吃掉前两者积累的成果。

## 11. 与其他系统的关系

1. 与直播间系统 共同定义三类房间分工。
2. 与带货收益系统 共同完成金币闭环。
3. 与广告与离线收益系统 共同决定短时放大方式。
4. 与资源系统总表 共同定义项目的核心上游资源。
