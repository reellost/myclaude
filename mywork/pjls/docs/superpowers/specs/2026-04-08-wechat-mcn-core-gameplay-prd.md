# 微信小游戏核心玩法需求文档 V1

## 1. 文档信息

- 文档名称：核心玩法需求文档
- 适用阶段：MVP 策划定义
- 对应产品：女主播逆袭与 MCN 公司成长模拟经营
- 文档日期：2026-04-08

## 2. 文档用途

本文件用于把项目的核心玩法从总需求和模块需求里单独抽离出来，形成一份可直接给策划、制作人、程序、美术统一理解的独立文档。

它重点回答以下问题：

1. 这款游戏的核心玩法到底是什么。
2. 玩家在游戏里最主要做哪些事情。
3. 游戏前期、中期、后期的体验如何变化。
4. 玩法的主要爽点、卡点和广告挂钩点分别是什么。
5. 首版应该保留哪些玩法，不该做哪些复杂内容。

## 3. 核心玩法定位

本项目的核心玩法定位为：

`轻放置 + 模拟经营 + 女性向逆袭养成`

玩家不是在做复杂的直播操作，也不是在玩重策略经营，而是在一条清晰的成长主线上持续做出简单投入，获得高频正反馈。

这条成长主线是：

`帮助被辞退的女主播重新开播 -> 让她变美、变自信、变专业 -> 通过自动直播获取流量 -> 用流量做带货赚钱 -> 扩建团队与公司 -> 最终做成 MCN 机构`

## 4. 核心玩法目标

核心玩法必须同时满足以下目标：

1. 玩家进入 1 分钟内能看懂玩法。
2. 玩家在前 10 分钟内持续有明确目标。
3. 玩法主线必须简单，不依赖复杂系统理解。
4. 女主个人成长必须有足够代入感。
5. 公司扩张必须在中后期形成明显规模感。
6. 广告必须自然挂在玩法卡点和奖励节点上。

## 5. 核心循环

### 5.1 总循环

游戏总循环如下：

`升级女主/直播间 -> 自动开播产流 -> 流量转化为带货收益 -> 用收益继续升级 -> 解锁公司成长与主播招募 -> 扩张团队 -> 获得更高流量与收益`

### 5.2 最小闭环

在最小一轮操作里，玩家体验到的闭环应是：

1. 点一次主角成长或直播间成长
2. 看到流量增长更快
3. 看到带货收益变多
4. 再拿这笔收益继续投入

### 5.3 长循环

在更长一轮成长里，玩家体验到的闭环应是：

1. 完成当前章节小目标
2. 解锁新页面、新商品或新主播
3. 收益和视觉反馈一起升级
4. 进入更像样的事业阶段

## 6. 玩家核心操作

首版玩家最主要的操作只有 6 类：

1. 升级女主
2. 升级直播间
3. 开播并观察产流
4. 选择当前主推商品
5. 升级公司
6. 招募与上阵主播

这些操作里，前 2 章主要围绕前 4 类展开；第 3 章后逐步加入后 2 类。

## 7. 双阶段玩法结构

为了保证题材代入和玩法清晰，首版玩法拆成两个阶段。

### 7.1 第一阶段：个人主播逆袭期

这个阶段的玩法重心是“养女主”。

玩家主要在做：

1. 化妆
2. 学技能
3. 穿搭升级
4. 整理直播间
5. 开播赚钱
6. 切换更合适的商品

这个阶段的核心感受是：

1. 女主越来越像样
2. 直播间越来越好看
3. 收益开始稳定增长
4. 玩家对她产生陪伴感和投入感

### 7.2 第二阶段：MCN 扩张期

这个阶段的玩法重心从“养一个人”扩展到“做一家公司”。

玩家主要在做：

1. 升级公司
2. 解锁更多直播位
3. 招募新主播
4. 上阵主播形成团队流量
5. 解锁更高价值商品位
6. 同时经营个人成长与团队扩张

这个阶段的核心感受是：

1. 我不只是把她养起来了
2. 我真的开始带团队了
3. 我的公司越来越像样
4. 每次扩张都能明显带来收益跳变

## 8. 核心系统在玩法中的职责

### 8.1 主角成长系统

职责：承接前期情绪投入，是最主要的前期成长玩法。

它在玩法里的作用：

1. 提供最直接的升级爽感
2. 负责“变美、变强、变自信”的可见成长
3. 作为前期主要数值投入点

### 8.2 直播间成长系统

职责：提供环境成长反馈，是前期第二重要投入方向。

它在玩法里的作用：

1. 让成长不只体现在角色，也体现在空间
2. 提供“房间越来越像样”的视觉满足
3. 对流量和带货效率形成辅助加成

### 8.3 开播产流系统

职责：把成长结果转化为持续上涨的流量。

它在玩法里的作用：

1. 承担自动化放置体验
2. 让玩家持续感知“我升级以后涨得更快了”
3. 为带货系统提供基础资源

### 8.4 带货收益系统

职责：把流量变成金币，是玩法里的赚钱桥梁。

它在玩法里的作用：

1. 承担经营感
2. 让商品选择变成一个轻决策点
3. 提供最直观的“赚钱了”反馈

### 8.5 公司成长系统

职责：把个人逆袭串成事业扩张，是后期长期目标框架。

它在玩法里的作用：

1. 负责章节推进和系统解锁
2. 让玩家始终知道下一步事业目标
3. 提供从个人主播到 MCN 的规模变化

### 8.6 招募主播系统

职责：承接中后期收集乐趣和团队扩张。

它在玩法里的作用：

1. 提供角色收集感
2. 提供公司扩张的直接反馈
3. 让中后期收益结构出现新的增长层

## 9. 玩家核心爽点

首版核心爽点建议集中在以下 5 类，不要做散：

### 9.1 女主变好看了

这是最直观的女性向成长爽点。

### 9.2 房间变像样了

这是空间和陪伴感带来的长期正反馈。

### 9.3 收益涨得很明显

这是放置经营的基础爽点，必须高频出现。

### 9.4 我终于招到新人了

这是从个人奋斗切到团队扩张的关键高潮。

### 9.5 公司真的变大了

这是项目长期驱动力，也是章节推进最重要的情绪奖励。

## 10. 玩家主要卡点

首版玩法里最容易出现的卡点主要有 4 类：

### 10.1 前期不知道该先点女主还是点房间

解决方式：通过任务和红点把主角成长设为第一优先，房间成长设为第二优先。

### 10.2 中段收益增长变慢

解决方式：用商品切换、公司升级和开播加速广告补节奏。

### 10.3 第 3 章前后第一次扩张理解成本上升

解决方式：首次招募和公司升级必须有明确引导，不让玩家同时理解太多新规则。

### 10.4 中后期广告过强或过弱

解决方式：通过离线收益控制、强广告错峰和章节节奏控制来平衡。

## 11. 玩法与广告的关系

广告不是额外系统，而是玩法节奏的补速器。

### 11.1 广告应挂的节点

1. 离线回流时：离线双倍
2. 章节奖励时：章节奖励翻倍
3. 中段卡点时：开播加速
4. 销售冲刺时：爆单翻倍
5. 内容解锁时：免费招募

### 11.2 广告不应挂的节点

1. 首次剧情演出中
2. 首次完整闭环前
3. 首次招募结果演出后立刻
4. 章节完成演出中间

### 11.3 玩法原则

玩家必须感觉：

1. 不看广告也能推进
2. 看广告会推进得更舒服
3. 广告是在帮我，不是在拦我

## 12. 会话节奏设计

### 12.1 单次短会话

玩家在一次 `1-3 分钟` 的短会话里，应至少能完成：

1. 一次收益领取
2. 一到两次成长升级
3. 一次明显的数值变化

### 12.2 中等会话

玩家在一次 `3-8 分钟` 的会话里，应能完成：

1. 一个小目标
2. 一次广告带来的明显推进
3. 一次章节任务推进或商品切换

### 12.3 长目标

玩家在累计更长时间后，应能完成：

1. 一次章节收尾
2. 一次新功能解锁
3. 一次从个人到公司层面的跃迁

## 13. 玩法中的页面承载关系

页面只是玩法的承载容器，不能反过来主导玩法。

首版建议的页面承载关系如下：

1. 主直播主界面：承接日常玩法和收益反馈
2. 主角成长页：承接前期主要升级行为
3. 直播间成长页：承接环境成长行为
4. 商品与带货页：承接轻经营决策
5. 公司成长页：承接长期目标和解锁
6. 招募页：承接中后期扩张高潮

## 14. MVP 核心玩法边界

首版必须坚持轻量，不做以下复杂玩法：

1. 不做节奏点击或舞蹈操作玩法
2. 不做复杂直播互动玩法
3. 不做库存、物流、供应链模拟
4. 不做深度主播羁绊和职业克制
5. 不做复杂装修编辑器
6. 不做重抽卡体验

首版只需要把下面这些做扎实：

1. 养女主
2. 升房间
3. 自动产流
4. 带货赚钱
5. 升公司
6. 招主播

## 15. 成功标准

如果核心玩法成立，玩家应表现出以下行为：

1. 前 1 分钟内能完成第一次完整闭环。
2. 前 10 分钟内愿意持续升级女主和直播间。
3. 第 3 章前后会明显期待“终于能招人了”。
4. 第 4-5 章时能明显感到公司扩张带来的收益跳变。
5. 看广告时会觉得值得，而不是觉得被打断。
